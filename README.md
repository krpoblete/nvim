# NeoVim Configuration

Personal NeoVim configuration for Laravel and PHP development.

## Features

* NeoVim 0.12+
* Lazy.nvim
* Telescope
* Treesitter
* Mason
* Intelephense
* nvim-cmp
* Conform + Laravel Pint
* ToggleTerm
* Harpoon
* Trouble
* Neo-tree
* Auto Session
* Which-Key

## Key Groups

* `<leader>c` Code
* `<leader>f` Find
* `<leader>h` Harpoon
* `<leader>l` Laravel
* `<leader>s` Session
* `<leader>t` Terminal
* `<leader>w` Windows
* `<leader>x` Diagnostics

Optimized for Laravel development on Linux.
